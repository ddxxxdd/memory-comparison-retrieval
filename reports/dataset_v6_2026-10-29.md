## 二、两项修改

**1. 主体写入正文**（833 条记录被改写）

- 泛称替换：`User / The user / My / I / 用户 / 我`、`Patient / The patient` → 该记忆 `user_id` 的固定化名；
  连 `Patient John Doe` 这类"泛称+单名"也整体替换。
- 无人称补主语：动词开头直接接名字（`Alice Chen started …`），名词短语用所有格（`Carol Chen's …`）；
  中文按句首词性决定加不加"的"（`Frank Davis完成了…` / `Karen Davis喜欢的书…`）。
- 原有单名规范化：`John / Emma / David / Bob / Alice` 等在多用户间复用的单名，替换成本用户的固定全名。
- 化名分配：575 个用户 → 574 个不同全名（一位用户的多条记忆共用同一名字）。
- **公共记忆不改**：`world` 作用域正文没有加任何人名。

**2. 过敏记录互斥化**（27 条）

- 统一加上"仅此一种"语义：`is only allergic to X`、`only allergy is X`、句末 `only`、中文 `仅对 X 过敏`。
- 药名一律保留，不删信息。
- 这样同一主体、不同过敏原的两条记录构成直接冲突，不再有"可以同时并存"的解释空间。
