# 四维失效/冲突探针与旧记忆库双极图扩散（`anchored_bipolar_diffusion`）

给定待写入的新记忆 $q$ 和同一用户的旧记忆库 $\mathcal{M}=\{m_1,\dots,m_N\}$，目标是把与 $q$ 矛盾、或因 $q$ 而失效的旧记忆排进前 $K$ 名，供下游逐条核查。检索时 LLM 只读 $q$，旧库通过冻结向量参与评分。[主包实现](../memory_retrieval/bipolar_graph.py)

本文描述 2026-11-23 的当前主方法，代码名保留 `anchored_bipolar_diffusion`，但当前提示词不生成 `new_state_anchor`。早期 OCSP-QR 正交投影仅作历史对照，不参与当前三个模块。检索输出是候选排序，不会自动确认冲突、删除旧记忆或写回数据库。[任务定义](research_problem_and_objectives.md) · [数据构建](stale_dataset_construction.zh.md) · [评测口径](evaluation_protocol.zh.md)

---

## 一、方法思路

1. **从新记忆生成探针。** 新旧记忆即使很少共用词语，也可能互相矛盾。LLM 直接以新记忆原句为既定事实，用四条短句写出可能受影响的旧事实。旧记忆与其中任一条相似，就能获得较高的初分。
2. **借助相邻旧记忆打分。** 同一状态可能出现在多条相关记忆中。每条旧记忆选出自己的相似邻居，如果邻居中有探针初分最高的种子，就按边权计入它的正向信号。
3. **用原句相似度作惩罚。** 如果一条旧记忆更接近新记忆原句，算法就用它与探针初分的差值计算惩罚，作用于它自身和选它作邻居的记忆。这是一条排序规则，真正失效的记忆也可能因此降分。

## 二、形式化算法流程与锁定参数

### 旧记忆编码与构图

主包 CLI 使用冻结编码器 `BAAI/bge-base-en-v1.5`，取 CLS 向量并做 L2 归一化，得到旧记忆矩阵 $X\in\mathbb{R}^{N\times d}$。在一份旧库内计算 $A=XX^\top$，对角线置零。每条记忆最多保留 $k=5$ 个正余弦邻居，按分数降序、`memory_id` 升序打破平局。边权按行归一化得到 $P$，没有正邻居时该行全为零。$P_{ij}$ 表示记忆 $i$ 给自己所选邻居 $j$ 的权重，同一旧库的查询共用这张图。

具体编码为 768 维、CPU FP32、最大 512 tokens、batch=4、4 线程、seed=0；正文去除首尾空白，不加检索指令前缀。模型 revision 与文件哈希由 [model_lock.json](../memory_retrieval/model_lock.json) 核对。T1/T2、官方/合成来源和 gold 都不输入编码器。超过最大长度的正文会截断，`token_audit` 记录该情况。

图是有向的，不对称化，不加自环，也不使用负边。“双极”指后续正负两类分数源，不表示图边被标注成冲突/相容关系。语义相近的邻居可能支持彼此，也可能互相矛盾，图本身不能判定逻辑关系。

### 从新记忆原句生成四条探针

每条查询对应一次逻辑生成请求，网络失败可能重试。用户消息只包含 `{"query": "新记忆正文"}`，不含旧库、官方旧句、金标、场景类型或官方解释。当前主包 CLI 固定模型为 `deepseek-v4.1-flash`，温度 0、JSON 模式、`reasoning_effort=none`；60 场景复现入口另按冻结协议核对模型配置。输出只有 `{"violation_probes": ["...", "...", "...", "..."]}`。英文提示词要求保留原句的主体、限制与适用时段，每条探针都用原句的语言写成不超过 30 词的肯定陈述，避免显式否定和复述。四条探针依次表达以下关系。

1. **相反或被替代的状态。** 与 $q$ 直接互斥，或被 $q$ 替代的旧状态、旧属性值。
2. **规则与实例的矛盾。** 违反 $q$ 中一般规则的具体事实，或被 $q$ 中具体事件打破的既有规则。
3. **失效的前提或依赖。** 一项持续状态、计划或依赖关系，其成立所必需的前提已被 $q$ 改变。
4. **互斥的条件或情境。** 与 $q$ 所蕴含事实无法并存的物理条件、时间条件或其他情境。

完整提示词是 `bipolar_graph.py` 的 `ANCHORED_FOUR_DIM_PROMPT`，UTF-8 SHA256 为 `a38b198018c62846780914f1ef90fe2461ee1554c421d42996f54525f93217bf`。四个维度是生成约束，评分时统一取最大相似度，没有逐维标签、专门权重或按 T1/T2 切换模板。输出是可能有用的旧陈述，不保证旧库实际存在该事实，也不保证模型生成的每条句子确实冲突。

结构校验只接受恰好一个键和四条非空字符串；截断、JSON 错误或结构错误会使主包报错停止。超过 30 词、出现显式否定、逐字复述或与查询余弦大于 0.85 等情况仅作审计标记，合法响应仍原样参与评分，不按金标或效果筛选重抽。因此提示词的“避免否定”不能写成“实际探针全部无否定”。温度为 0 也不保证远端服务两次输出逐字相同；复现时以请求缓存和保存的响应为准。

### 初始打分与正负源

使用同一冻结编码器将 $q$ 与四条探针编码为单位向量 $\mathbf{v}_q$ 和 $\{\mathbf{u}_j^-\}_{j=1}^4$。每条旧记忆 $\mathbf{x}_i$ 的探针初分与原句相似度分别为

$$r_{0,i} = \max_{j \in \{1,\dots,4\}} \mathbf{x}_i^\top \mathbf{u}_j^-, \qquad s_i^+ = \mathbf{x}_i^\top \mathbf{v}_q$$

正种子向量 $\mathbf{z}_{\text{pos}}$ 仅保留 $\mathbf{r}_0$ 排名前 `top_seeds = 5` 的原始分数，其余位置置零。负源向量 $\mathbf{z}_{\text{neg}}$ 取原句相似度超出探针初分的部分。

$$z_{\text{neg}, i} = \max\!\big(0,\; s_i^+ - r_{0,i}\big)$$

种子不足 5 条时取全部；种子选择不使用金标或语义阈值，所保留的是原分数，代码没有额外把负的种子分数截为零。$s_i^+$ 是“与原句相似度”，不是“相容概率”；负源也不是已确认负例。一个真实冲突句可能与原句非常相近，因而受到误压制。

### 一步双极图扩散与全库排序

使用锁定参数 $k=5,\ \text{top\_seeds}=5,\ \alpha=0.2,\ \beta=0.3$，计算每条旧记忆的最终得分。

$$\mathbf{r} = (1-\alpha)\,\mathbf{r}_0 + \alpha\,(P\,\mathbf{z}_{\text{pos}}) - \beta\,\big(\mathbf{z}_{\text{neg}} + \alpha\,(P\,\mathbf{z}_{\text{neg}})\big)$$

其中 $(P\mathbf z)_i=\sum_j P_{ij}z_j$，即记忆 $i$ 从自己选出的邻居汇聚信号。按 $\mathbf r$ 对该查询对应的整个旧库降序排序，分数相同时按 `memory_id` 升序排列，取前 $K$ 条作为候选。

这里只执行一步矩阵乘法，不迭代至收敛，也不使用 $P^\top$。正扩散同时把原初分乘以 $1-\alpha$，并非原分数上无条件加分；负项同时包含自身扣分和邻域扣分。某条邻居收到种子信息，不表示这条邻居已经被证明冲突。

## 三、主方法与两项消融

三个实验臂共享同一批探针和向量，两种扩散共用同一张旧库图。

| 实验臂名称 | 计算公式 | 作用 |
|---|---|---|
| `anchored_probes_only` | $\mathbf{r}_0$ | 四条探针最大余弦 |
| `anchored_pos_diffusion` | $(1-\alpha)\mathbf{r}_0 + \alpha P\mathbf{z}_{\text{pos}}$ | 加入正种子的邻域信号 |
| `anchored_bipolar_diffusion` | $(1-\alpha)\mathbf{r}_0 + \alpha P\mathbf{z}_{\text{pos}} - \beta(\mathbf{z}_{\text{neg}} + \alpha P\mathbf{z}_{\text{neg}})$ | 完整方法，加入自身与邻域的负向惩罚 |

模块的实测贡献须绑定数据版本。当前 V2 数值见[最新 60 场景实验](../reports/stale_v2_60scene_bipolar_seed20261122_experiment.md)；[V1 模块收益与误伤核验](../reports/stale_unseen_60scene_native_bank_and_module_audit_seed20261122.md)用于历史诊断，不能把其中 Qwen 或原生单目标结论当作 V2 结果。

## 四、执行流程与计算边界

```text
读取查询及其场景旧库；来源标签与 gold 只用于核查和评测
编码该场景旧库 X，构建一次邻居矩阵 P
对新记忆 q 生成四条探针，编码 q 和探针
计算探针初分 r0、Top-5 种子 z_pos 和差值负源 z_neg
一次计算仅探针、正扩散、双极完整方法的分数
各臂分别全库排序，保存完整排名；按 K 截取评测
```

三个臂共享生成调用，图不增加 LLM 请求。主包按场景在本次运行中构图；已有旧库的向量和图原则上可以复用，但当前通用 CLI 没有实现生产数据库的增量图维护，也没有只为新增记忆更新索引的接口。不得把这一潜在优化写成已经测得的在线性能。

当前图实现先形成稠密 $N\times N$ 余弦矩阵，并保存同尺寸的邻接/转移矩阵。构图相似度计算约 $O(N^2d)$，逐行完整排序约 $O(N^2\log N)$，内存约 $O(N^2)$；虽然每行只保留 k 条非零边，当前存储和矩阵运算仍为稠密实现。单查询探针相似度约 $O(4Nd)$，扩散矩阵乘法约 $O(N^2)$，最终排序约 $O(N\log N)$。已有数百条场景库实验不能直接证明百万条库上的扩展性。

候选预算 K、图邻居数 k 和种子数是三个不同量。现有统一入口保存排名，报告 Top-3/5/10 等指标；没有通过可靠度阈值自动判断“无需返回候选”的功能。实验中使用 gold 计算指标，不把 gold 传入图评分函数。

## 五、适用假设与验证要求

四维探针的动机是为隐式冲突建立检索线索；图扩散的假设是相关旧记忆之间能传递有用信号；负源的假设是原句更相近而探针较远的条目较可能是干扰。这些都是待实证检验的假设，三个模块不必在每种数据上都提高指标。

当前固定参数不构成“从未接触测试数据”或“已经排除数据构造偏差”的证明。合成数据作者与检索探针使用同名模型，尽管提示词和输入不同，仍应报告这一来源并通过独立数据及同 LLM 预算对照检验。新增方法选择应在开发数据上完成，冻结后再评测独立留出数据；已查看的 60 场景以及其 V2 扩库版不能再次称为未见样本。评测与后续研究目标的区分见[评测口径](evaluation_protocol.zh.md)。
