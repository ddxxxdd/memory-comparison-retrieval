# STALE 原生旧库对照与模块收益/误伤分析

本轮结论：去掉新增合成记忆后，完整方法仍优于 Dense：BGE Top-10 为 53/60 对 42/60，Qwen 为 55/60 对 50/60；两底座 NDCG@10 差值的 Wilcoxon 检验显著且 Bootstrap 95% CI 均大于 0。BGE 完整方法也显著优于 SparseCL MS MARCO。

模块结论需要收窄：原生单目标评测中，正扩散相对仅探针的总体 NDCG 增益没有达到显著（BGE p=0.3513，Qwen p=0.7894，两个 CI 均含 0）。BGE 正扩散 Top-10 从 49 增到 52，但 NDCG 从 0.6779 降到 0.6627；Qwen Top-10 从 54 增到 56，NDCG 从 0.7725 微升到 0.7800。增加候选覆盖不等同于提高前排排序质量。负向抑制在两个原生设置中均降低了正扩散的总体 NDCG。

扩增库细账则显示正扩散仍有明确净召回收益：BGE 拉回 32、推走 14，Qwen 拉回 29、推走 4；Qwen 负向压制拉回 1、推走 3，净少 2 个 Top-10 目标。原生/扩增对照同时改变候选组成与评测目标数，不据此单独断言差异完全由合成语义簇造成。

同一批 seed=20261122 的 30 T1＋30 T2，沿用 240 条原探针与缓存向量。LLM、Qwen Embedding 以及其他 API 调用均为 0；BGE 和 SparseCL 也直接复用缓存，没有重新加载模型编码。
