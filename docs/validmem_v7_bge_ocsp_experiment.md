# ValidMem v7：统一 BGE 的冲突候选检索实验

2026-11-19 · 探索性评估

**核心结果：** 完整 OCSP-QR 比 BGE Dense 多命中 9 个 Top-1 金标，但在 Top-3/5/10 均未超过 Dense。仅违例探针的 Top-1 和 NDCG@10 最好；加入 QR 后，本次所有报告预算的配对命中数都下降。

## 数据集与设置

- **数据：** 当前本地 `validmem_v7` 全量，181 条查询、1,225 条共享旧记忆、301 对金标。57 条查询有多个金标。按原标签定义，冲突包括同主体、同事项的不同取值或状态更新，不等同于上一轮低词面重合的单对隐式冲突。原文和标签均未修改，不翻译、不筛样本。
- **统一设置：** 用同一旧记忆库、查询和候选预算，只用正文打分。向量方法共享冻结的 `BAAI/bge-base-en-v1.5` 基础编码器（CLS、L2 归一化，最长 512 词元，CPU FP32、批大小和线程数均为 4、种子 0）。不在本数据集重训或调参，不调用下游冲突判定器。
- **基线：** BM25 用原词项匹配（`k1=1.2`、`b=0.75`）；Dense 用基础 BGE 的原句余弦；Hybrid 等权融合 BM25 和 Dense 排名（RRF 常数 60）。SparseCL 以同一 BGE 做 HNSW Top-1,000 初召回，保留 ArguAna、MS MARCO、HotpotQA 三组 BGE 微调权重及原余弦–Hoyer 融合（`α=0.18 / 2.19 / 4.82`）。三组的初召回集合相同，覆盖全部 301 对金标。
- **新方法与消融：** 沿用 `deepseek-v4.1-flash` 和原零样本提示词，每条查询生成 2 条相容改述、3 条违例探针。仅探针取最高违例余弦；完整 OCSP-QR 加入原 QR 投影和门控打分（`γ=0.65`）。LLM 只读新记忆，旧库无 LLM 抽取。探针从空缓存生成，181 条查询共 184 次 API 尝试（含 3 次重试）、95,556 个已知词元；6 并发生成用时约 609 秒，随后原脚本重放同请求响应。这不是单条查询时延；六条基线均不调用 LLM。

## 固定预算结果

Top-K 列为命中金标对数，共 301 对。配对召回 = 命中数 ÷ 301；候选纯度 = 命中数 ÷ (181 × K)。Top-10 找全数是所有金标均进入前 10 的查询数，分母为 181。

## 怎么解读

- **第一条排得更好，不代表候选集找得更全。** 完整 OCSP-QR 的第一条命中 161/181 条查询，Dense 为 152/181；但 Top-10 配对召回为 89.0% 对 91.4%，找全查询 172 对 177。两条查询分别有 14、29 个金标，因此 Top-10 的配对召回上限是 278/301（92.4%），Dense 已接近这个上限。
- **没有观察到 QR 在本集的额外收益。** 相比仅探针，完整方法在 Top-1 少命中 13 对，在 Top-10 少命中 3 对。原自适应阈值（`0.50 / 0.05`，每条最多 5 个）返回 902 个候选、命中 228/301（纯度 25.3%）；Dense 按每条完全相同的候选数截断，命中 258/301。
- **与 15 条隐式冲突集的区别。** 用相同 BM25 分词，ValidMem 金标对平均词项 Jaccard 为 0.536，[15 条隐式冲突集](single_pair_implicit_15q_bge_experiment.md)为 0.064。比如同一个人的常去超市从 Walmart 更新为 Trader Joe’s，一对新旧记忆共享主体和事项，原句检索已有直接线索。因此这次结果和隐式集上的提升并不矛盾：当前证据不支持用 OCSP-QR 全面替代 Dense。
- **语言与标注边界。** 原文中 7 条查询、62 条旧记忆含汉字；英文 BGE 对查询、旧记忆的未知词元比例分别为 2.2%、3.3%，无截断。生成的 905 条文本中也有 60 条含汉字；例如 `TW-0006` 的新旧记忆都是英文数学练习册版本，探针却生成了中文，并举出英语和物理教材，Dense 中两条金标排第 1、2，OCSP-QR 中掉到第 80、54。本次未分离探针语义和语言不匹配的影响。v7 已用于开发，且金标并非全量独立人工复核，不把本结果视为独立盲测。

**复核与复现：** 核对了原数据与快照哈希、全部 181 条查询的候选覆盖、两套脚本共有方法的排名一致性，并从原始排名重算表中指标。见[统一结果与逐查询金标位置](../runs/experiments/validmem-v7-bge-ocsp-20261119/comparison.json)、[基线配置](../runs/experiments/validmem-v7-bge-ocsp-20261119/baselines/run_config.json)、[OCSP-QR 原始结果](../runs/experiments/validmem-v7-bge-ocsp-20261119/ocsp/summary.json)、[逐查询探针](../runs/experiments/validmem-v7-bge-ocsp-20261119/ocsp/per_query_details.json)和[汇总脚本](../runs/experiments/validmem-v7-bge-ocsp-20261119/summarize.py)。
