# 15 查询英文集：六个基线与锚定双极图扩散

2026-11-20。使用当前主包，在 `single_pair_implicit_15q_en` 上完整运行六个基线及最新 `anchored_bipolar_diffusion`。本轮未运行旧 OCSP-QR、旧探针方法或额外消融，未修改数据、提示词或评分参数。

## 数据与配置

数据为 15 条查询、225 条共享旧记忆、15 对金标，每条查询恰好一个目标。所有方法都返回同一旧库的完整 225 项排名。该集合经过多轮构造与诊断，是探索性数据集，不能作为独立未见 Test 泛化证明。

- 共享冻结 `BAAI/bge-base-en-v1.5`，revision `a5beb1e3e68b9ab74eb54cfd186867f64f240e1a`；CLS、L2 归一化、最长 512 词元，CPU FP32、4 线程、batch=4、seed=0。BGE 加载一次，原句和旧库向量供各方法复用。
- BM25：`k1=1.2, b=0.75`；Dense：原文余弦；Hybrid：等权 RRF，常数 60。
- SparseCL：完整使用 ArguAna、MS MARCO、HotpotQA 的官方冻结训练检查点、平均池化和 `cosine + α × Hoyer` 评分；对应权重为 `0.18 / 2.19 / 4.82`。HNSW 初召回在本轮覆盖全部 225 条记忆。
- 新方法：LLM 只读新记忆，生成一个锚点和四条失效/冲突探针；锚点不编码。请求和返回模型名称均为 `deepseek-v4.1-flash`，4 并发、温度 0、JSON 模式、`reasoning_effort=none`。提示词 SHA256：`0bf33d0094a328f8d4cd796b26f1f389aee5196e7f2f2fc77bd553c9c0008fcf`。
- 图扩散固定为正余弦有向 Top-5 邻接、零对角、按行归一化；Top-5 正种子保留原分数。使用 `α=0.2, β=0.3` 及 `r=0.8*r0+0.2*(P@z_pos)-0.3*(z_neg+0.2*(P@z_neg))`，未针对本数据集调参。

原服务不可用时的运行已停止，保留在 [中断记录](../runs/experiments/single-pair-15q-anchored-bge-20261120/interruption.json)。用户更新 LLM 服务配置后，在新目录完成本轮；没有从中断轮混入探针。算法、模型名称、数据和参数保持一致。
